# Intrusive Red-Black Tree (`kernel/lib/rbtree`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a correct, generic, intrusive red-black tree with an
augmented-subtree-aggregate mechanism and an O(1)-leftmost cached
variant to `kernel/lib/`, proven by a boot-time selftest.

**Architecture:** A classic CLRS red-black tree, written from the
algorithm (not copied from Linux), but with a **Linux-compatible API
surface** (`struct rb_node` embedded in the caller's struct, colour
packed into the parent pointer's low bit, `rb_link_node` +
`rb_insert_color` two-step insert, `rb_erase`, `rb_first/next/…`
iteration). Adds `struct rb_root_cached` (caches the leftmost node for
O(1) min) and an augmented core (`rb_insert_augmented` /
`rb_erase_augmented` + a `struct rb_augment_callbacks`) so a subtree
aggregate — EEVDF's `min_vruntime`, a deadline tree's max slack, a
timer wheel's earliest-expiry — is maintained through rotations. The
EEVDF-specific augment callbacks are **not** in this plan; they live in
`kernel/sched/fair.c` (SCH-1) and only *use* this mechanism.

**Tech Stack:** C11, freestanding kernel (`-ffreestanding -mno-sse
-mcmodel=kernel`, no libc). Boot-verified via headless QEMU + serial
log; no host unit tests (`CLAUDE.md`).

**Spec:** `docs/superpowers/specs/2026-09-07-advanced-scheduler-design.md`
(section "SCH-1 — EEVDF fair-class core" → "Data-structure work", and
the "Risks / open questions" note that this must land first standalone).

## Global Constraints

- Language: C11, kernel build flags as above. No dynamic allocation
  inside the tree operations — the tree is **intrusive**: the caller
  owns the `struct rb_node` storage (embedded in its own struct).
- Do not copy code from Linux's `lib/rbtree.c` (GPL). Implement from
  the CLRS algorithm. The *API names and shapes* may mirror Linux's
  (they are the de-facto kernel idiom and cost nothing).
- No host-runnable tests. The test is `rbtree_selftest()`, a function
  that prints exactly one of `[rbtree] selftest passed` or
  `[rbtree] selftest FAILED: <reason>` and is called from
  `kernel/kernel.c` during boot.
- Verification per step: `make clean-kernel iso disk-image QUIET=1`
  then boot headless and `grep` the serial log. The one-liner
  (used verbatim in every "run" step below):

  ```bash
  cd ~/projects/personal/NeoOS && \
  make clean-kernel iso disk-image QUIET=1 2>&1 | grep -iE "error:|Error [0-9]" ; \
  timeout 150 qemu-system-x86_64 -cpu Nehalem -smp 4 -boot order=d \
    -cdrom build/neoos.iso -drive file=build/disk.img,format=raw \
    -drive file=build/disk2.img,format=raw -vga std \
    -netdev user,id=n0 -device virtio-net-pci,netdev=n0 \
    -audiodev none,id=a0 -device AC97,audiodev=a0,addr=0x6 \
    -no-reboot -display none -serial file:build/serial.rb.log > /dev/null 2>&1 ; \
  grep -nE "\[rbtree\]|PANIC|\[exception\]" build/serial.rb.log
  ```
- `kernel/lib/*.c` and `*.h` are auto-globbed by the Makefile
  (`KERNEL_DIRS` includes `kernel/lib`) — no Makefile edit needed to
  add files, only to add the marker (Task 4).
- Full `tools/gauntlet.sh 15 3` at zero retries at the end.
- Selftest style: match `kernel/mm/wxorx_selftest.c` /
  `kernel/lib/rand.c`'s `rand_selftest()` — a single `void
  foo_selftest(void)` that returns early on the first failure after
  printing `FAILED: <reason>`, and prints `passed` only if it reached
  the end.

## File Structure

- **Create `kernel/lib/rbtree.h`** — public types (`struct rb_node`,
  `struct rb_root`, `struct rb_root_cached`,
  `struct rb_augment_callbacks`), the colour/parent accessors as

  rebalancing algorithm.
- **Create `kernel/lib/rbtree_selftest.c`** — `rbtree_selftest()` and
  its private helpers (a tiny xorshift PRNG so it does not depend on

- **Modify `kernel/lib/rbtree.h`** — add `void rbtree_selftest(void);`
  (or a separate `rbtree_selftest.h`; a single header is fine for
  something this small — follow `rand.h`, which declares both
  `rand_*` and `rand_selftest`).
- **Modify `kernel/kernel.c`** — call `rbtree_selftest()` in the
  boot selftest block (near `rand_selftest()` / `heap_selftest()` —

  but keeping it with the other `lib` selftests is tidy).
- **Modify `Makefile`** — add `"[rbtree] selftest passed"` to

  ```c
  struct rb_node {
      uintptr_t __rb_parent_color;   // parent ptr | colour (bit 0: 1=red? NO: 0=red,1=black — see note)
      struct rb_node *rb_right;
      struct rb_node *rb_left;
  } __attribute__((aligned(sizeof(uintptr_t))));

  struct rb_root { struct rb_node *rb_node; };
  #define RB_ROOT (struct rb_root){ 0 }
  #define RB_EMPTY_ROOT(root) ((root)->rb_node == 0)

  // container_of
  #define rb_entry(ptr, type, member) \
      ((type *)((char *)(ptr) - offsetof(type, member)))

  // two-step insert: caller does the BST descent, links the node,
  // then calls rb_insert_color to rebalance.
  static inline void rb_link_node(struct rb_node *node,
                                  struct rb_node *parent,
                                  struct rb_node **rb_link);
  void rb_insert_color(struct rb_node *node, struct rb_root *root);

  struct rb_node *rb_first(const struct rb_root *root);
  struct rb_node *rb_last(const struct rb_root *root);
  struct rb_node *rb_next(const struct rb_node *node);
  struct rb_node *rb_prev(const struct rb_node *node);

  void rbtree_selftest(void);
  ```
  **Colour-bit note:** pack colour into `__rb_parent_color`'s bit 0.
  Choose `0 = RED`, `1 = BLACK` so a freshly `rb_link_node`'d node
  (parent pointer written, bit 0 clear) is RED by construction, which
  is what the insert-fixup expects. Document this choice in
  `rbtree.h`.

- [ ] **Step 1: Write the failing selftest (`kernel/lib/rbtree_selftest.c`)**

```c
// kernel/lib/rbtree_selftest.c
#include "lib/rbtree.h"
#include "drivers/char/serial.h"
#include <stdint.h>
#include <stddef.h>

struct tnode {
    struct rb_node rb;
    uint32_t key;
};

// A local PRNG so this test does not depend on rand.c's init order.
static uint64_t prng_state = 0x2545F4914F6CDD1DULL;
static uint32_t prng(void) {
    uint64_t x = prng_state;
    x ^= x << 13; x ^= x >> 7; x ^= x << 17;
    prng_state = x;
    return (uint32_t)(x >> 32);
}

static void fail(const char *why) {
    serial_write_string("[rbtree] selftest FAILED: ");
    serial_write_string(why);
    serial_write_string("\n");
}

#define POOL 4096
static struct tnode pool[POOL];
static int in_tree[POOL];   // 1 if pool[i] is currently linked

static struct tnode *tn_insert(struct rb_root *root, uint32_t key, int idx) {
    struct rb_node **link = &root->rb_node, *parent = 0;
    while (*link) {
        struct tnode *t = rb_entry(*link, struct tnode, rb);
        parent = *link;
        if (key < t->key)       link = &(*link)->rb_left;
        else                    link = &(*link)->rb_right;   // dup keys go right
    }
    pool[idx].key = key;
    rb_link_node(&pool[idx].rb, parent, link);
    rb_insert_color(&pool[idx].rb, root);
    return &pool[idx];
}

// Returns black-height, or -1 on any invariant violation.
static int check(struct rb_node *n, int *ok) {
    if (!n) return 1;  // NIL leaves are black, height 1
    struct rb_node *l = n->rb_left, *r = n->rb_right;
    // colour bit: 0 = RED, 1 = BLACK
    int black = (n->__rb_parent_color & 1);
    if (!black) {
        if ((l && !(l->__rb_parent_color & 1)) ||
            (r && !(r->__rb_parent_color & 1))) { *ok = 0; return -1; } // red-red
    }
    // parent back-pointers
    if (l && ((struct rb_node *)(l->__rb_parent_color & ~(uintptr_t)3) != n)) { *ok=0; return -1; }
    if (r && ((struct rb_node *)(r->__rb_parent_color & ~(uintptr_t)3) != n)) { *ok=0; return -1; }
    // BST order
    if (l && rb_entry(l, struct tnode, rb)->key > rb_entry(n, struct tnode, rb)->key) { *ok=0; return -1; }
    if (r && rb_entry(r, struct tnode, rb)->key < rb_entry(n, struct tnode, rb)->key) { *ok=0; return -1; }
    int bl = check(l, ok), br = check(r, ok);
    if (bl < 0 || br < 0 || bl != br) { *ok = 0; return -1; }
    return bl + black;
}

void rbtree_selftest(void) {
    struct rb_root root = RB_ROOT;

    // 1. Insert POOL random keys, verify invariants after each.
    for (int i = 0; i < POOL; i++) {
        tn_insert(&root, prng(), i);
        in_tree[i] = 1;
        if ((i & 0x1ff) == 0x1ff) {  // check every 512 inserts
            int ok = 1;
            if (root.rb_node && !(root.rb_node->__rb_parent_color & 1)) { fail("root not black"); return; }
            check(root.rb_node, &ok);
            if (!ok) { fail("invariant violated during insert"); return; }
        }
    }
    { int ok = 1; check(root.rb_node, &ok); if (!ok) { fail("invariant after full insert"); return; } }

    // 2. In-order traversal is sorted and visits every node once.
    uint32_t prev = 0; int seen = 0; int first = 1;
    for (struct rb_node *n = rb_first(&root); n; n = rb_next(n)) {
        uint32_t k = rb_entry(n, struct tnode, rb)->key;
        if (!first && k < prev) { fail("rb_next not sorted"); return; }
        prev = k; first = 0; seen++;
    }
    if (seen != POOL) { fail("rb_next visited wrong count"); return; }

    // 3. Reverse traversal matches.
    int rseen = 0;
    for (struct rb_node *n = rb_last(&root); n; n = rb_prev(n)) rseen++;
    if (rseen != POOL) { fail("rb_prev visited wrong count"); return; }

    serial_write_string("[rbtree] selftest passed\n");
}
```

- [ ] **Step 1: Extend the selftest with a delete phase**

Add to `rbtree_selftest()` after the traversal checks, before the

```c
    // 4. Random delete-half / re-insert churn, invariants after each batch.
    for (int round = 0; round < 20; round++) {
        // delete a random ~1/4 of what's in the tree
        for (int i = 0; i < POOL; i++) {
            if (in_tree[i] && (prng() & 3) == 0) {
                rb_erase(&pool[i].rb, &root);
                in_tree[i] = 0;
            }
        }
        int ok = 1;
        if (root.rb_node && !rb_is_black(root.rb_node)) { fail("root red after erase"); return; }
        check(root.rb_node, &ok);
        if (!ok) { fail("invariant violated during erase"); return; }
        // re-insert some of the free slots
        for (int i = 0; i < POOL; i++) {
            if (!in_tree[i] && (prng() & 1)) {
                tn_insert(&root, prng(), i);
                in_tree[i] = 1;
            }
        }
        ok = 1; check(root.rb_node, &ok);
        if (!ok) { fail("invariant violated during re-insert"); return; }
    }

    // 5. Count matches in_tree[].
    int want = 0; for (int i = 0; i < POOL; i++) want += in_tree[i];
    int have = 0; for (struct rb_node *n = rb_first(&root); n; n = rb_next(n)) have++;
    if (have != want) { fail("node count drifted after churn"); return; }

    // 6. Erase everything; tree must end empty.
    for (int i = 0; i < POOL; i++) if (in_tree[i]) { rb_erase(&pool[i].rb, &root); in_tree[i] = 0; }
    if (!RB_EMPTY_ROOT(&root)) { fail("tree not empty after erasing all"); return; }
```

  ```c
  struct rb_root_cached {
      struct rb_root rb_root;
      struct rb_node *rb_leftmost;
  };
  #define RB_ROOT_CACHED (struct rb_root_cached){ {0}, 0 }

  // Caller does the BST descent, tracking whether it went left at
  // every step (leftmost == "went left the whole way").
  void rb_insert_color_cached(struct rb_node *node,
                              struct rb_root_cached *root, int leftmost);
  void rb_erase_cached(struct rb_node *node, struct rb_root_cached *root);
  static inline struct rb_node *rb_first_cached(const struct rb_root_cached *r)
      { return r->rb_leftmost; }

  // Augmented: the callbacks maintain a per-node subtree aggregate
  // through rotations. `propagate` recomputes node's aggregate from
  // its children and returns non-zero to stop early; `copy` moves
  // old's aggregate to new on a rotation; `rotate` recomputes after
  // a rotation swaps old<->new.
  struct rb_augment_callbacks {
      void (*propagate)(struct rb_node *node, struct rb_node *stop);
      void (*copy)(struct rb_node *old, struct rb_node *newn);
      void (*rotate)(struct rb_node *old, struct rb_node *newn);
  };
  void rb_insert_augmented(struct rb_node *node, struct rb_root *root,
                           const struct rb_augment_callbacks *augment);
  void rb_insert_augmented_cached(struct rb_node *node,
                                  struct rb_root_cached *root, int leftmost,
                                  const struct rb_augment_callbacks *augment);
  void rb_erase_augmented(struct rb_node *node, struct rb_root *root,
                          const struct rb_augment_callbacks *augment);
  void rb_erase_augmented_cached(struct rb_node *node,
                                 struct rb_root_cached *root,
                                 const struct rb_augment_callbacks *augment);
  ```

- [ ] **Step 1: Extend the selftest — cached leftmost + a test augment**

Add a second node type carrying a subtree aggregate (sum of keys in
the subtree) and its three callbacks, then a phase that:
- builds a cached tree with `rb_insert_augmented_cached` (computing
  `leftmost` during the BST descent),
- after every batch: asserts `rb_first_cached(&root) == rb_first(&root.rb_root)`,
- asserts every node's `subtree_sum` equals the brute-force sum of
  its subtree's keys (walk the subtree),
- does erase churn with `rb_erase_augmented_cached` and re-checks
  both properties.

```c
struct anode { struct rb_node rb; uint32_t key; uint64_t subtree_sum; };

static uint64_t brute_sum(struct rb_node *n) {
    if (!n) return 0;
    struct anode *a = rb_entry(n, struct anode, rb);
    return a->key + brute_sum(n->rb_left) + brute_sum(n->rb_right);
}
static void a_propagate(struct rb_node *node, struct rb_node *stop) {
    for (; node != stop; node = rb_parent(node)) {
        struct anode *a = rb_entry(node, struct anode, rb);
        uint64_t s = a->key;
        if (node->rb_left)  s += rb_entry(node->rb_left,  struct anode, rb)->subtree_sum;
        if (node->rb_right) s += rb_entry(node->rb_right, struct anode, rb)->subtree_sum;
        if (a->subtree_sum == s) break;   // no change above -> stop
        a->subtree_sum = s;
    }
}
static void a_copy(struct rb_node *old, struct rb_node *newn) {
    rb_entry(newn, struct anode, rb)->subtree_sum =
        rb_entry(old, struct anode, rb)->subtree_sum;
}
static void a_rotate(struct rb_node *old, struct rb_node *newn) {
    // newn took old's place; recompute old (now a child) then newn.
    a_copy(old, newn);
    struct anode *a = rb_entry(old, struct anode, rb);
    uint64_t s = a->key;
    if (old->rb_left)  s += rb_entry(old->rb_left,  struct anode, rb)->subtree_sum;
    if (old->rb_right) s += rb_entry(old->rb_right, struct anode, rb)->subtree_sum;
    a->subtree_sum = s;
}
static const struct rb_augment_callbacks A_CB = { a_propagate, a_copy, a_rotate };
```
