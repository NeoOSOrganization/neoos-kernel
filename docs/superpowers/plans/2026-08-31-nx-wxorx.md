# NX / W^X Enforcement — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make "no page is both writable and executable" a real
invariant — enforced in the ELF loader, in `mmap`/`mprotect`, and
across the kernel address space, with a boot-time selftest.

**Architecture:** The ELF loader stops mapping every segment writable
and honors `p_flags` instead. `vma_mmap`/`vma_mprotect` reject
`PROT_WRITE|PROT_EXEC` with `-EINVAL` (a deliberate, recorded
divergence from Linux). A post-paging pass in `paging_init` walks the
kernel PML4, splitting the boot's 2 MiB huge pages where a section
boundary falls and setting RO on `.text`/`.rodata` and NX on
everything that is not code. EFER.NXE is already set per-CPU
(`syscall.c:339`).

**Tech Stack:** C (freestanding), NASM, x86-64, GNU Make, headless
QEMU + serial-log assertions, the parallel gauntlet
(`.superpowers/sdd/2026-08-31-phase14-input-and-solidity/pgauntlet.sh`,
CONC=3).

**Spec:** `docs/superpowers/specs/2026-08-31-nx-wxorx-design.md`

## Task 1: Audit userland binaries; add linker symbols

**Files:**
- Inspect: every `build/userland/*.ELF`
- Modify: `linker.ld`

- [ ] **Step 1: check for RWX load segments in the userland binaries**

Run:
```bash
make iso disk-image >/dev/null 2>&1
for f in build/userland/*.ELF; do
  echo "== $f =="; readelf -l "$f" | grep -A1 'LOAD'
done
```
Expected: each `LOAD` line's flags are `R E` (text) or `RW ` (data),
never `RWE`. If any is `RWE`, the userland link flags produce a single
merged segment — add `-Wl,-z,noexecstack -Wl,-z,separate-code` (or
`-Wl,-z,max-page-size=0x1000` plus explicit `.text`/`.data` PHDRS in
`userland/user.ld`) and re-check. **Do not proceed until every binary
is clean** — Task 2's loader check would otherwise refuse to run them.

- [ ] **Step 2: add section-boundary symbols to `linker.ld`**

In the higher-half `SECTIONS`, ensure each of `.text`, `.rodata`,
`.data`, `.bss` is `ALIGN(4K)` (they already are) and bracket them:
```ld
    .text ALIGN(4K) : AT(ADDR(.text) - KERNEL_VIRT_BASE) {
        __text_start = .;
        *(.text .text.*)
        . = ALIGN(4K);
        __text_end = .;
    }
    .rodata ALIGN(4K) : AT(ADDR(.rodata) - KERNEL_VIRT_BASE) {
        __rodata_start = .;
        *(.rodata .rodata.*)
        . = ALIGN(4K);
        __rodata_end = .;
    }
    .data ALIGN(4K) : AT(ADDR(.data) - KERNEL_VIRT_BASE) {
        __data_start = .;
        *(.data .data.*)
        ...
    }
```
Grep the kernel for existing `__text_start` etc. first; reuse if
present.

- [ ] **Step 3: build, verify symbols resolve**

Run: `make build && x86_64-elf-nm build/kernel.elf | grep -E '__(text|rodata|data)_(start|end)'`
Expected: four (or five) symbols, `.text` range < `.rodata` range <
`.data` range, all page-aligned.

- [ ] **Step 4: gauntlet + commit**

`"NX/W^X: audit userland segments; add kernel section symbols"`.

## Task 2: ELF loader honors `p_flags`

**Files:**
- Modify: `kernel/elf.c` (the PT_LOAD mapping loop, ~line 88)

**Interfaces:**
- `ELF_PF_X` (1) exists; add `ELF_PF_W` (2), `ELF_PF_R` (4) if absent.

- [ ] **Step 1: failing test — a purpose-built RO-text check**

`userland/mmaptest.c` (or a new tiny `userland/nxtest.c`): take the
address of `main`, `mprotect(page_of(&main), 4096, PROT_READ|PROT_WRITE)`
— today this **succeeds** because the text segment is mapped writable.
Assert it returns `-EACCES` (a RO mapping cannot be made writable
without the vma allowing it — see how `vma_mprotect` treats a region
whose vma prot lacks `PROT_WRITE`... note: for a non-mmap'd ELF
segment there may be no vma; in that case the test is "writing to
`&main` faults with SIGSEGV" caught via a handler). Pick whichever the
code makes checkable and write the assertion.

Run `make test 2>&1 | grep -E 'nxtest|FAILED'` → expect the assertion
to FAIL on today's kernel (text is writable).

- [ ] **Step 2: implement**

In `elf_load`, replace the fixed `flags = PAGE_WRITABLE | PAGE_USER`:
```c
uint64_t flags = PAGE_USER;
if (ph->p_flags & ELF_PF_W)  { flags |= PAGE_WRITABLE; }
if (!(ph->p_flags & ELF_PF_X)) { flags |= PAGE_NO_EXECUTE; }
if ((ph->p_flags & ELF_PF_W) && (ph->p_flags & ELF_PF_X)) {
    serial_write_string("[elf] refusing W+X load segment\n");
    return -ENOEXEC;    // or the loader's existing failure convention
}
```
The BSS-tail zero-fill keeps the segment's flags (a `.bss` in a
writable segment stays writable).

- [ ] **Step 3: test passes; full suite still runs**

`make test` — `nxtest` passes; **every** existing userland binary
still loads and runs (`[*] ALL PASSED` for all suites). A binary that
now fails to load had an RWX segment Task 1 missed — go back and fix
its link.

- [ ] **Step 4: gauntlet ×1 + commit**

`"NX/W^X: ELF loader maps segments per p_flags, refuses in-file W+X"`.

## Task 4: kernel address space — split huge pages, set RO/NX

**Files:**
- Modify: `kernel/mm/paging.c`, `kernel/mm/paging.h`
- Create: `kernel/mm/wxorx_selftest.c`
- Modify: `kernel/kernel.c` (call site), `Makefile` (`REQUIRED_MARKERS`)

**Interfaces:**
- Produces:
  ```c
  int  paging_split_huge(uint64_t virt);   // 2MiB leaf -> 512 4KiB; 0 ok, <0 oom
  void paging_protect_kernel(void);        // the RO/NX pass
  void wxorx_selftest(void);
  ```

- [ ] **Step 1: `paging_split_huge`**

Given a virtual address whose PD entry is a `PAGE_HUGE` leaf: allocate
a PT frame (`alloc_table_frame` — the same helper `paging.c` already
uses), fill 512 entries `phys_base + i*4096` with the huge entry's
flags minus `PAGE_HUGE`, install the PT into the PD entry (drop
`PAGE_HUGE`), `invlpg` the 2 MiB range (or reload CR3). If the PD
entry is already a PT, return 0. Uses the deferred-free discipline
from `tlb.c` if it must replace an entry a CPU could be walking — at
`paging_protect_kernel` time only the BSP runs, so a plain CR3 reload
is fine; assert `smp_cpu_count()==1` or run before AP bring-up.

- [ ] **Step 2: `paging_protect_kernel`**

Walk `[__text_start, kernel_phys_end + KERNEL_VIRT_BASE)` at 4 KiB
granularity (splitting any huge page that overlaps a boundary first):
```
for va in kernel range, step 4096:
    e = pte_for(va)
    if !present: continue
    if va in [__text_start,  __text_end):   e &= ~PAGE_WRITABLE; e &= ~PAGE_NO_EXECUTE
    else if va in [__rodata_start, __rodata_end): e &= ~PAGE_WRITABLE; e |= PAGE_NO_EXECUTE
    else:                                   e |= PAGE_NO_EXECUTE   # .data/.bss
    write e
reload CR3
```
Then the **physmap** window (`PHYSMAP_PML4_INDEX`): set `PAGE_NO_EXECUTE`
on its PDPT/PD entries (they are 1 GiB / 2 MiB — NX on a non-leaf
entry is fine and covers everything below). Leave it writable (it is
the kernel's data view of RAM).

Call it from `paging_init`'s tail — after `heap_init` and the physmap
are up (the walk allocates PT frames), before `process_init` / AP
bring-up.

- [ ] **Step 3: `wxorx_selftest`**

```c
void wxorx_selftest(void) {
    uint64_t bad = 0;
    for (va = KERNEL_VIRT_BASE; va < end; va += 4096) {
        e = pte_for(va); if (!(e & PAGE_PRESENT)) continue;
        if ((e & PAGE_WRITABLE) && !(e & PAGE_NO_EXECUTE)) { bad = va; break; }
    }
    if (bad) { serial_write_string("[wxorx] kernel selftest FAILED at "); serial_write_hex64(bad); ... }
    else       serial_write_string("[wxorx] kernel selftest passed\n");
    // negative probe: prove vma_mmap would reject W+X without faulting
    // (call a tiny exported helper wxorx_mmap_would_reject(PROT_W|PROT_X))
}
```
Add `"[wxorx] kernel selftest passed"` to `REQUIRED_MARKERS`.

- [ ] **Step 4: run — expect it to reveal reality**

`make test`. Likely outcomes and what they mean:
- `[wxorx] kernel selftest passed` + all suites green → done.
- A `#PF` early in boot → a legitimate kernel code path was executing
  from a page just marked NX, or writing to one just marked RO. That
  is a real W^X violation the audit must resolve (e.g. a trampoline in
  `.data`, self-modifying code). Fix the code, not the flags.
- `[wxorx] ... FAILED at <va>` → decode `<va>` with `nm`/`addr2line`;
  a section symbol is wrong or a huge page was not split.
