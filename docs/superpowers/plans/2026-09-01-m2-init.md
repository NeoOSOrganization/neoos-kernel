# M2 — init (PID 1) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make PID 1 a real ring-3 process that reads a manifest, launches the workload, reaps every orphan, and powers the machine off when the workload is done — so the kernel stops knowing the test list.

**Architecture:** A `reboot(2)` syscall (PID-1-only). `/SBIN/INIT`, a libneoos program the kernel starts as PID 1: parse `/ETC/INITTAB`, `spawnv` each entry, `wait4(-1)` forever, `reboot(POWER_OFF)` at `-ECHILD`. The kernel reparents an exiting process's children to PID 1 and panics if PID 1 itself exits. `kmain` drops its ~26 hard-coded spawns for one `spawn("/SBIN/INIT.ELF")`; the `user_proc_count` poweroff hack is deleted.

**Tech Stack:** C (freestanding kernel, `-mcmodel=kernel`; userland `-mcmodel=large`, libneoos), GNU Make, headless QEMU + serial-log assertions, the parallel gauntlet (`.superpowers/sdd/2026-08-31-phase14-input-and-solidity/pgauntlet.sh`, CONC=2).

**Spec:** `docs/superpowers/specs/2026-09-01-m2-init-design.md`

## Global Constraints

- **No host unit tests.** Each task's test is a userland binary or a kernel selftest, verified by `make test` (headless QEMU, 4 CPUs, powers off in ~11s) and, after each task, the parallel gauntlet reaching `PGAUNTLET PASSED: 15/15`. Task 3 gates ×3 (init is on the boot critical path for every userland test).
- **`make test` compiles with `-DNEOOS_TEST_HOOKS`; a plain `make iso` (the gauntlet) does not.** No test-only kernel path may misbehave in production, and a userland test that calls a hook must tolerate `-ENOSYS`.
- **`SYS_MAX` is 69 today** (`SYS_POLL` 67, `SYS_SELECT` 68). `SYS_REBOOT` = 69, `SYS_MAX` → 70. The syscall-table selftest asserts every slot `< SYS_MAX` has a non-null handler.
- **The proc-table iterator is `proc_table_for_each_ref(fn, ctx)`** (`kernel/sched/proc_table.h`) — batched, refcounted, **holds no lock during the callback**, and is **not reentrant** (do not call it from inside another `_for_each_ref`).
- **`pid_alloc` starts at 1** (`kernel/sched/pid_alloc.c:58`, PID 0 = idle), so the first `spawn()` gets PID 1.
- **`spawnv(path, argv)`** already sets `argv[0]` to `path` when given a bare path; init passes `{ path, NULL }` explicitly anyway. `wait4(-1, &st, 0, 0)` returns any child's pid, or `-ECHILD` when there are none.
- **Lock ranks:** this plan adds no locks. The reparent walk runs under the proc-table lock (`LOCK_RANK_PROCTABLE` 0) that `proc_table_for_each_ref` takes internally.

- [ ] **Step 3: `sys_reboot`**

`syscall_nr.h`: `#define SYS_REBOOT 69` and `#define SYS_MAX 70`.
`syscall_internal.h`: `int64_t sys_reboot(struct syscall_args *a);`
`syscall.c` table: `[SYS_REBOOT] = { sys_reboot, "reboot" },`.
`sys_proc.c`:
```c
#include "kernel.h"   // kernel_shutdown

#define REBOOT_RESTART   0x01234567u
#define REBOOT_HALT      0xcdef0123u
#define REBOOT_POWER_OFF 0x4321fedcu

int64_t sys_reboot(struct syscall_args *a) {
    struct process *p = current_proc();
    if (!p || p->pid != 1) { return -EPERM; }
    switch ((uint32_t)a->a1) {
    case REBOOT_POWER_OFF:
        kernel_shutdown();                     // ACPI S5, never returns
        break;
    case REBOOT_HALT:
        __asm__ volatile ("cli");
        for (;;) { __asm__ volatile ("hlt"); }
    case REBOOT_RESTART:
        // 8042 pulse; if the platform ignores it, triple-fault.
        __asm__ volatile ("outb %0, %1" :: "a"((uint8_t)0xFE), "Nd"((uint16_t)0x64));
        for (volatile int i = 0; i < 1000000; i++) { }
        { struct { uint16_t limit; uint64_t base; } __attribute__((packed)) idt0 = { 0, 0 };
          __asm__ volatile ("lidt %0; int3" :: "m"(idt0)); }
        break;
    default:
        return -EINVAL;
    }
    return 0;   // unreachable for the three real commands
}
```

- [ ] **Step 1: failing test — `userland/orphantest.c`**

```c
#include <unistd.h>
#include <stdio.h>
#include <sys/wait.h>

// A grandchild whose parent (our child) exits immediately is orphaned.
// It must still run to completion and be reaped by init -- if init's
// wait4(-1) loop did not pick up reparented orphans, the machine would
// never reach reboot() and `make test` would time out. This test also
// checks the direct mechanics from userland where it can.
int main(void) {
    int child = fork();
    if (child == 0) {
        int gc = fork();
        if (gc == 0) {
            // grandchild: outlive our parent, then exit cleanly
            for (volatile long i = 0; i < 30000000; i++) { }
            printf("[orphantest] grandchild done\n");
            _exit(0);
        }
        _exit(0);                    // parent exits now -> grandchild orphaned
    }
    int st;
    wait4(child, &st, 0, 0);         // reap our direct child

    // We cannot wait4() the grandchild -- it is init's now. A wait4(-1)
    // here must return -ECHILD (we have no children left), NOT the
    // grandchild.
    int r = wait4(-1, &st, 0, 0);
    if (r != -1) {
        printf("[orphantest] FAILED: wait4(-1) returned %d, expected -ECHILD\n", r);
        return 1;
    }
    printf("[orphantest] ALL PASSED\n");
    return 0;
}
```

Wire the Makefile rule + disk copy + temporary `kmain` spawn.

- [ ] **Step 1: `userland/init.c`**

```c
#include <unistd.h>
#include <stdio.h>
#include <fcntl.h>
#include <string.h>
#include <sys/wait.h>
#include <sys/reboot.h>

#define MAX_ENTRIES 64
#define MODE_SPAWN 0
#define MODE_WAIT  1
#define MODE_RESPAWN 2

static struct { char path[64]; int mode; } ents[MAX_ENTRIES];
static int nents;

// pid -> entry index, for respawn (M2 ships no respawn entries; dormant).
static int rp_pid[MAX_ENTRIES];
static int rp_ent[MAX_ENTRIES];
static int nrp;

static int mode_of(const char *w, int len) {
    if (len == 5 && !memcmp(w, "spawn", 5))   { return MODE_SPAWN; }
    if (len == 4 && !memcmp(w, "wait", 4))    { return MODE_WAIT; }
    if (len == 7 && !memcmp(w, "respawn", 7)) { return MODE_RESPAWN; }
    return -1;
}

static void parse_inittab(void) {
    int fd = open("/ETC/INITTAB", O_RDONLY);
    if (fd < 0) { printf("[init] no /ETC/INITTAB (%d)\n", fd); return; }
    static char buf[4096];
    int n = 0, r;
    while ((r = read(fd, buf + n, sizeof buf - n)) > 0) { n += r; if (n >= (int)sizeof buf) break; }
    close(fd);

    int i = 0;
    while (i < n && nents < MAX_ENTRIES) {
        int ls = i;
        while (i < n && buf[i] != '\n') { i++; }
        int le = i; i++;                       // past the newline
        // trim, skip blank / comment
        while (ls < le && (buf[ls] == ' ' || buf[ls] == '\t')) { ls++; }
        if (ls >= le || buf[ls] == '#') { continue; }
        int ws = ls; while (ls < le && buf[ls] != ' ' && buf[ls] != '\t') { ls++; }
        int m = mode_of(buf + ws, ls - ws);
        while (ls < le && (buf[ls] == ' ' || buf[ls] == '\t')) { ls++; }
        int ps = ls; while (le > ps && (buf[le-1] == ' ' || buf[le-1] == '\t' || buf[le-1] == '\r')) { le--; }
        if (m < 0 || le <= ps || (le - ps) >= (int)sizeof ents[0].path) {
            printf("[init] bad inittab line, skipped\n"); continue;
        }
        memcpy(ents[nents].path, buf + ps, le - ps);
        ents[nents].path[le - ps] = 0;
        ents[nents].mode = m;
        nents++;
    }
}

static int launch(int e) {
    char *argv[2] = { ents[e].path, 0 };
    int pid = spawnv(ents[e].path, argv);
    if (pid < 0) { printf("[init] spawn %s failed (%d)\n", ents[e].path, pid); return -1; }
    if (ents[e].mode == MODE_RESPAWN && nrp < MAX_ENTRIES) { rp_pid[nrp] = pid; rp_ent[nrp] = e; nrp++; }
    return pid;
}

int main(void) {
    parse_inittab();
    if (nents == 0) { printf("[init] empty inittab -- powering off\n"); reboot(LINUX_REBOOT_CMD_POWER_OFF); }

    int launched = 0;
    for (int e = 0; e < nents; e++) {
        if (ents[e].mode == MODE_WAIT) {
            int pid = launch(e);
            if (pid > 0) { int st; wait4(pid, &st, 0, 0); }
        } else {
            if (launch(e) > 0) { launched++; }
        }
    }
    printf("[init] %d entries launched, reaping\n", launched);

    for (;;) {
        int st;
        int pid = wait4(-1, &st, 0, 0);
        if (pid < 0) { break; }              // -ECHILD: nothing left to reap
        for (int k = 0; k < nrp; k++) {
            if (rp_pid[k] == pid) { rp_pid[k] = launch(rp_ent[k]); break; }
        }
    }
    printf("[init] all entries exited -- powering off\n");
    reboot(LINUX_REBOOT_CMD_POWER_OFF);
    for (;;) { }
}
```
