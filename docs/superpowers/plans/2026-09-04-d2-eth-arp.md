# D2 — Ethernet, ARP and routing: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: use
> `superpowers:executing-plans` (or `subagent-driven-development`) to
> work this plan task by task. Steps use `- [ ]` checkboxes.

**Goal:** `netdev.transmit` means "here is an IPv4 packet, get it to the
other end" for *every* device, including the NIC — which means framing,
address resolution and a route table.

**Architecture:** a new link layer (`eth.c`) sits between `net.c` and the
driver. It owns the 14-byte header and the ethertype demux. Below it,
`arp.c` owns a 16-entry cache with a one-packet pending slot per entry.
Beside them, `route.c` replaces `net_route`'s hardcoded "always
loopback" with a four-entry longest-prefix table.

**Tech Stack:** C11, freestanding, x86_64. No host test runner — every
test is an in-kernel selftest whose PASS/FAIL lands on COM1 and is
grepped out of the serial log by `make test`.

**Spec:** `docs/superpowers/specs/2026-09-04-d2-d5-network-stack-design.md`

## Global Constraints

- **Linux-shaped ABI.** Nothing in D2 crosses into userland, so D2 is
  free to name things as it likes — but `docs/abi-compatibility.md` is
  refreshed at the end of the *track*, not per stage.
- **Lock ranks are checked at runtime.** `LOCK_RANK_ARP` must rank
  strictly below `LOCK_RANK_NETRX` (13) and above `LOCK_RANK_SOCKET`
  (12) — see the D1 spec's "One design point corrected".
- **Never hold a spinlock across `virtio_net_transmit`.** It spins
  waiting on the device. Copy out under the lock, transmit after.
- **No dynamic allocation on the receive path.** Fixed tables only.
- **Every new suite joins `REQUIRED_MARKERS`** in the Makefile in the
  same commit that adds it. A suite that never runs is not a pass.
- **Every detector is proven by breaking it**, watching it fire, and
  reverting — the table goes in the results section.
- The test cycle for every task below is:
  `make test` → read `build/serial.log` → the new marker must FAIL
  before the implementation and PASS after.

### Task 1: The route table

**Files:**
- Create: `kernel/net/route.h`, `kernel/net/route.c`
- Modify: `kernel/net/net.c` (`net_route` delegates), `kernel/net/net.h`
- Test: `route_selftest()` inside `route.c`, called from `net_selftest`

**Interfaces:**
- Produces:
```c
#define ROUTE_MAX 4
struct netdev;
// Adds a route. `gw_n == 0` means "on link". Longest prefix wins.
// Returns 0, or -ENOSPC.
int  route_add(uint32_t dst_n, uint32_t mask_n, uint32_t gw_n, struct netdev *dev);
// Removes every route whose device is `dev`. Used when a lease changes.
void route_flush_dev(struct netdev *dev);
// The device for `dst_n`, and the address ARP must resolve: `dst_n`
// itself when the route is on-link, the gateway when it is not.
// Returns 0 when nothing matches; *next_hop_n is untouched then.
struct netdev *route_lookup(uint32_t dst_n, uint32_t *next_hop_n);
void route_init(void);      // installs 127.0.0.0/8 -> lo
void route_selftest(void);
```
- Consumes: `struct netdev` from `net.h`.

- [ ] **Step 1: Write the failing selftest.**

In `route.c`:

```c
void route_selftest(void) {
    serial_write_string("[route] selftest\n");
    int failed = 0;
    struct netdev *lo = net_loopback();
    struct netdev fake = { .name = "fake", .type = NETDEV_ETHERNET,
                           .ip_n = 0x0F02000Au /* 10.0.2.15 */ };
    // 10.0.2.0/24 on link, and a default via 10.0.2.2.
    if (route_add(0x0002000Au, 0x00FFFFFFu, 0, &fake) != 0)      { failed = 1; }
    if (route_add(0, 0, 0x0202000Au, &fake) != 0)                { failed = 1; }

    uint32_t nh = 0;
    // loopback wins for 127/8, and the next hop is the address itself
    if (route_lookup(0x0100007Fu, &nh) != lo || nh != 0x0100007Fu) {
        serial_write_string("[route] FAILED: 127.0.0.1 did not route to lo\n");
        failed = 1;
    }
    // on-link: next hop is the destination
    nh = 0;
    if (route_lookup(0x0902000Au, &nh) != &fake || nh != 0x0902000Au) {
        serial_write_string("[route] FAILED: on-link next hop wrong\n");
        failed = 1;
    }
    // off-link: next hop is the gateway, NOT the destination
    nh = 0;
    if (route_lookup(0x08080808u, &nh) != &fake || nh != 0x0202000Au) {
        serial_write_string("[route] FAILED: default route next hop is not the gateway\n");
        failed = 1;
    }
    // longest prefix wins: /24 must beat /0 for an address in both
    nh = 0;
    if (route_lookup(0x0102000Au, &nh) != &fake || nh != 0x0102000Au) {
        serial_write_string("[route] FAILED: /0 beat /24\n");
        failed = 1;
    }
    route_flush_dev(&fake);
    if (route_lookup(0x08080808u, &nh) != 0) {
        serial_write_string("[route] FAILED: flush left a route behind\n");
        failed = 1;
    }
    serial_write_string(failed ? "[route] FAILED\n" : "[route] ALL PASSED\n");
}
```

Note the fourth case: it is the one that catches a table that returns
the *first* match instead of the *longest*, which is the bug every
hand-written route table has on its first day.

- [ ] **Step 2: Run it and watch it fail.**

`make test`, then `grep -n '\[route\]' build/serial.log`.
Expected: a link error, or `[route] FAILED` — not `ALL PASSED`.

- [ ] **Step 3: Implement `route.c`.**

A `struct route table[ROUTE_MAX]` plus a count, no lock (see below).
`route_add` refuses duplicates of the same dst/mask by overwriting.
`route_lookup` walks all entries, keeps the match with the greatest
mask popcount, and sets `*next_hop_n = gw_n ? gw_n : dst_n`.
`route_init` adds `127.0.0.0/8 -> net_loopback()`.

**No lock**, and the reason is written into the file: the table is
written by `route_init` at boot and by the DHCP thread at lease change,
and read by every transmit. Reads of a four-entry array of aligned
words cannot tear into a *wrong* answer — only into a stale one, which
a route table is allowed to be for one packet. A lock here would be
taken on every single transmit to protect a write that happens twice a
day. When routing becomes writable from userland, this comment is the
place that says why that changes.

- [ ] **Step 4: Add `net_loopback()`** to `net.c`/`net.h`, returning the
      loopback device — `route.c` needs it and the loopback device is
      currently file-static.

- [ ] **Step 5: Make `net_route` delegate.**

```c
struct netdev *net_route(uint32_t dst_ip_n) {
    uint32_t nh;
    return route_lookup(dst_ip_n, &nh);
}
```

Keep the name: `socket.c` calls it in four places to answer "is this
address reachable", and that question has not changed.

- [ ] **Step 6: Call `route_init()` from `net_init()`** before the
      loopback device is used, and `route_selftest()` from
      `net_selftest()`.

- [ ] **Step 7: Run `make test`.** Expected `[route] ALL PASSED`, and
      `[nettest] ALL PASSED` still present — the loopback socket suite
      must not notice that routing changed underneath it.

- [ ] **Step 8: Prove the detector.** Change `route_lookup` to return
      the first match rather than the longest; confirm
      `FAILED: /0 beat /24`; revert.

- [ ] **Step 9: Commit.**

```bash
git add kernel/net/route.c kernel/net/route.h kernel/net/net.c kernel/net/net.h
git commit -m "net: a route table, so there can be more than one device"
```

### Task 2: Ethernet framing and the demux

**Files:**
- Create: `kernel/net/eth.h`, `kernel/net/eth.c`
- Modify: `kernel/net/net.h` (reword the `transmit` contract),
  `kernel/kernel.c` (`netrx_set_handler(eth_input)`)

**Interfaces:**
- Consumes: `route_lookup` (Task 1), `arp_resolve` (Task 3 — write Task 3
  first if working strictly in order; the two tasks are split for review,
  not for compilation).
- Produces:
```c
#define ETH_HDR_LEN   14
#define ETH_TYPE_IPV4 0x0800
#define ETH_TYPE_ARP  0x0806
#define ETH_MIN_FRAME 60      // without FCS; the device appends that

struct eth_header {
    uint8_t  dst[6];
    uint8_t  src[6];
    uint16_t ethertype_n;
} __attribute__((packed));

// netrx's handler. Runs on the netrx thread; sleeping is allowed.
void eth_input(struct netdev *dev, const uint8_t *frame, uint32_t len);
// Builds a frame around `pkt` and hands it to dev->transmit_frame.
// Pads to ETH_MIN_FRAME. Returns 0 or a negative errno.
int  eth_send(struct netdev *dev, const uint8_t dst_mac[6],
              uint16_t ethertype, const uint8_t *pkt, uint32_t len);
// The netdev->transmit hook for an Ethernet device: resolves the next
// hop and sends. Returns 0, or -EHOSTUNREACH when ARP gives up, or
// 0 with the packet QUEUED when ARP is still resolving.
int  eth_output_ipv4(struct netdev *dev, const uint8_t *pkt, uint32_t len);
void eth_stats(uint64_t *rx_ip, uint64_t *rx_arp, uint64_t *rx_unknown,
               uint64_t *tx_frames);
```

- [ ] **Step 1: Write `eth.h`** exactly as above, with
      `_Static_assert(sizeof(struct eth_header) == 14, "...")`.

- [ ] **Step 2: Implement `eth_send`.**

Copies header + payload into a per-call stack buffer of
`ETH_FRAME_MAX` (1514), zero-pads to 60, calls `dev->transmit_frame`.
A `len` that would exceed 1500 returns `-EMSGSIZE`. The zero-pad is not
cosmetic: a 42-byte ARP request is legal on QEMU and illegal on a real
switch, and that is a bug that only appears on hardware.

- [ ] **Step 3: Implement `eth_input`.**

```c
void eth_input(struct netdev *dev, const uint8_t *frame, uint32_t len) {
    if (len < ETH_HDR_LEN) { return; }
    const struct eth_header *h = (const struct eth_header *)frame;
    uint16_t type = ntohs_k(h->ethertype_n);
    const uint8_t *payload = frame + ETH_HDR_LEN;
    uint32_t plen = len - ETH_HDR_LEN;
    switch (type) {
    case ETH_TYPE_IPV4: rx_ip++;      net_ipv4_input(dev, payload, plen); break;
    case ETH_TYPE_ARP:  rx_arp++;     arp_input(dev, payload, plen);      break;
    default:            rx_unknown++;                                     break;
    }
}
```

No log line in the default case. A real segment carries broadcast
traffic NeoOS has no opinion about, and one serial write per frame is a
denial of service against the boot.

- [ ] **Step 4: Implement `eth_output_ipv4`.**

```c
int eth_output_ipv4(struct netdev *dev, const uint8_t *pkt, uint32_t len) {
    uint32_t next_hop = 0;
    const struct ipv4_header *ip = (const struct ipv4_header *)pkt;
    if (len < 20) { return -EINVAL; }
    if (!route_lookup(ip->dst_n, &next_hop)) { return -ENETUNREACH; }
    uint8_t mac[6];
    int rc = arp_resolve(dev, next_hop, mac, pkt, len);
    if (rc != 0) { return rc; }   // queued (0 via the pending slot) or -EHOSTUNREACH
    return eth_send(dev, mac, ETH_TYPE_IPV4, pkt, len);
}
```

`arp_resolve` returning `-EAGAIN` means "queued, will go out when the
reply lands", and `eth_output_ipv4` translates that to 0 for its
caller: the packet is not lost, and a caller who is told "error" for a
packet that is about to be sent will send it twice.

- [ ] **Step 5: Point the driver at it.** In `virtio_net.c`, set
      `dev.transmit = eth_output_ipv4` and delete the `-ENETUNREACH`
      stub and the comment above it. Reword `net.h`'s `transmit` /
      `transmit_frame` comments: `transmit` now means the same thing for
      every device, and `transmit_frame` is the link layer's private
      door.

- [ ] **Step 6: `netrx_set_handler(eth_input)`** in `kernel.c`, replacing
      D1's counting handler.

- [ ] **Step 7: `make test`.** Nothing new asserts yet; what must hold is
      that `[virtio-net] ALL PASSED` still passes. D1's selftest builds
      its own ARP request and calls `virtio_net_transmit` directly, so it
      is unaffected by the seam moving — if it broke, the seam moved
      wrongly.

- [ ] **Step 8: Commit.**

```bash
git add kernel/net/eth.c kernel/net/eth.h kernel/net/net.h \
        kernel/drivers/net/virtio_net.c kernel/kernel.c
git commit -m "net: a link layer, so transmit() means one thing everywhere"
```

### Task 3: The ARP cache

**Files:**
- Create: `kernel/net/arp.h`, `kernel/net/arp.c`
- Modify: `kernel/sync/lock.h` (`LOCK_RANK_ARP`), `kernel/kernel.c`
- Test: `arp_selftest()` in `arp.c`

**Interfaces:**
- Consumes: `eth_send` (Task 2), `route_lookup` (Task 1).
- Produces:
```c
#define ARP_CACHE_MAX     16
#define ARP_VALID_TICKS   (60 * TIMER_HZ)
#define ARP_RETRY_TICKS   (1 * TIMER_HZ)
#define ARP_MAX_REQUESTS  3

struct arp_packet {           // Ethernet + IPv4 only; 28 bytes
    uint16_t htype_n, ptype_n;
    uint8_t  hlen, plen;
    uint16_t op_n;            // 1 request, 2 reply
    uint8_t  sha[6]; uint32_t spa_n;
    uint8_t  tha[6]; uint32_t tpa_n;
} __attribute__((packed));

void arp_init(void);
// Called by eth_input on the netrx thread.
void arp_input(struct netdev *dev, const uint8_t *pkt, uint32_t len);
// Fills `mac` and returns 0 when the answer is known.
// Returns -EAGAIN having QUEUED a copy of (pkt,len) when a request has
// been sent and the answer is not known yet.
// Returns -EHOSTUNREACH when the cache is full or the peer is dead.
int  arp_resolve(struct netdev *dev, uint32_t ip_n, uint8_t mac[6],
                 const uint8_t *pkt, uint32_t len);
// Called once per timer tick from the netrx thread's drain loop:
// retries pending requests and expires valid entries.
void arp_tick(void);
void arp_selftest(void);
```

- [ ] **Step 1: Add `LOCK_RANK_ARP`.**

In `kernel/sync/lock.h`, insert at 13 and shift `LOCK_RANK_NETRX` and
everything above it up by one, exactly as D1 did when it moved
`LOCK_RANK_NETRX`. The comment must say *why* 13: `arp_resolve` is
called from a transmitting thread that holds nothing above it, and
`arp_input` is called from the netrx thread which holds nothing at all —
so ARP ranks below NETRX and never sleeps.

- [ ] **Step 2: Write the failing selftest.**

```c
void arp_selftest(void) {
    serial_write_string("[arp] selftest\n");
    int failed = 0;
    struct netdev *dev = net_device();
    if (!dev) { serial_write_string("[arp] SKIPPED: no NIC\n"); return; }

    // 1. Resolve the gateway THROUGH THE LAYER. D1 proved the wire by
    //    hand; this proves the cache, the pending slot and completion.
    uint8_t mac[6];
    uint8_t dummy[20] = {0};
    int rc = arp_resolve(dev, 0x0202000Au /* 10.0.2.2 */, mac, dummy, sizeof dummy);
    if (rc == -EAGAIN) {
        for (int i = 0; i < 200 && rc == -EAGAIN; i++) {
            arp_wait_a_tick();
            rc = arp_lookup_only(0x0202000Au, mac);
        }
    }
    if (rc != 0) {
        serial_write_string("[arp] FAILED: gateway never resolved\n");
        failed = 1;
    } else if (mac[0] == 0 && mac[1] == 0 && mac[2] == 0) {
        serial_write_string("[arp] FAILED: gateway resolved to a null MAC\n");
        failed = 1;
    }

    // 2. A request for OUR address produces a correctly formed reply.
    struct arp_packet req = {
        .htype_n = htons_k(1), .ptype_n = htons_k(ETH_TYPE_IPV4),
        .hlen = 6, .plen = 4, .op_n = htons_k(1),
        .sha = {2,0,0,0,0,1}, .spa_n = 0x0302000Au,
        .tha = {0}, .tpa_n = dev->ip_n,
    };
    uint64_t before = arp_replies_sent();
    arp_input(dev, (const uint8_t *)&req, sizeof req);
    if (arp_replies_sent() != before + 1) {
        serial_write_string("[arp] FAILED: no reply to a request for our own address\n");
        failed = 1;
    }
    // and it must have LEARNED the sender
    if (arp_lookup_only(0x0302000Au, mac) != 0 || mac[5] != 1) {
        serial_write_string("[arp] FAILED: did not learn from a request addressed to us\n");
        failed = 1;
    }

    // 3. A request for SOMEONE ELSE produces nothing.
    req.tpa_n = 0x6402000Au;   // 10.0.2.100
    before = arp_replies_sent();
    arp_input(dev, (const uint8_t *)&req, sizeof req);
    if (arp_replies_sent() != before) {
        serial_write_string("[arp] FAILED: replied on behalf of another address\n");
        failed = 1;
    }

    // 4. An entry expires rather than being used forever.
    arp_force_expire(0x0302000Au);
    if (arp_lookup_only(0x0302000Au, mac) == 0) {
        serial_write_string("[arp] FAILED: expired entry was still used\n");
        failed = 1;
    }

    // 5. A truncated packet is dropped, not parsed.
    before = arp_replies_sent();
    arp_input(dev, (const uint8_t *)&req, 10);
    if (arp_replies_sent() != before) {
        serial_write_string("[arp] FAILED: parsed a truncated ARP packet\n");
        failed = 1;
    }
    serial_write_string(failed ? "[arp] FAILED\n" : "[arp] ALL PASSED\n");
}
```

Test helpers `arp_lookup_only`, `arp_replies_sent`, `arp_force_expire`
and `arp_wait_a_tick` are part of the interface and declared in
`arp.h` — a test that needs to reach inside says so in the header
rather than by `extern`-ing a static.

`arp_wait_a_tick` is `hlt`, **not** `schedule()`: kmain is not a thread,
and calling `schedule()` from a boot-time selftest switches away from a
bootstrap stack there is nothing to save into. D1 learned this the
expensive way and the comment in `arp.c` must say so.

- [ ] **Step 3: Run it and watch it fail.** `make test`; expect a link
      error or `[arp] FAILED`.

- [ ] **Step 4: Implement the cache.**

```c
struct arp_entry {
    uint32_t ip_n;
    uint8_t  mac[6];
    uint8_t  state;              // ARP_FREE / ARP_PENDING / ARP_VALID
    uint8_t  requests;
    uint64_t deadline;           // expiry when VALID, next retry when PENDING
    struct netdev *dev;
    uint32_t pending_len;
    uint8_t  pending[1500];      // ONE packet, deliberately
};
```

`arp_resolve`: take the lock; look up. VALID → copy the MAC, drop the
lock, return 0. PENDING → replace the pending packet, drop the lock,
return `-EAGAIN`. Miss → claim a FREE entry (or the oldest VALID one if
none is free), store the packet, set `requests = 1` and
`deadline = now + ARP_RETRY_TICKS`, drop the lock, **then** send the
request. `-EHOSTUNREACH` only when there is no entry to claim at all.

- [ ] **Step 5: Implement `arp_input`.**

Drop anything shorter than 28 bytes, or whose htype/ptype/hlen/plen are
not `1 / 0x0800 / 6 / 4`. Then, in this order:

1. **Learn**: if an entry for `spa_n` exists, update its MAC and make it
   VALID with a fresh deadline. If it was PENDING, copy the queued
   packet out, drop the lock, and send it.
2. **Create on demand**: only if the packet is a *request* whose
   `tpa_n` is one of our addresses.
3. **Reply**: if it is a request for one of our addresses, build a
   reply (swap sender/target, op = 2, sha = our MAC) and `eth_send` it
   to the requester's MAC. Increment `replies_sent`.

The order matters. Learning before replying is what makes the reply go
to a cache entry that already exists rather than creating a second one.

- [ ] **Step 6: Implement `arp_tick`,** called from the netrx thread's
      loop once per tick: PENDING entries past their deadline resend and
      bump `requests`, or are freed (dropping the queued packet) once
      `requests > ARP_MAX_REQUESTS`; VALID entries past their deadline
      become FREE.

- [ ] **Step 7: Wire it up.** `arp_init()` in `kernel.c` after
      `net_init()`; `arp_selftest()` after `virtio_net_selftest()` — it
      needs the NIC, the netrx thread, and the APs, for the same reason
      D1's selftest does.

- [ ] **Step 8: `make test`.** Expected `[arp] ALL PASSED`.

- [ ] **Step 9: Prove the detectors.** Four breaks, each reverted:

| Break | Must fire |
|---|---|
| never send the request in `arp_resolve` | `gateway never resolved` |
| reply to every request regardless of `tpa_n` | `replied on behalf of another address` |
| skip the learn step in `arp_input` | `did not learn from a request addressed to us` |
| drop the length check | `parsed a truncated ARP packet` |

- [ ] **Step 10: Add `"[arp] ALL PASSED"` to `REQUIRED_MARKERS`,** and
      `kernel/net` is already in `KERNEL_DIRS`.

- [ ] **Step 11: Commit.**
