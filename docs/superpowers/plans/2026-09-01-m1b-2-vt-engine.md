# M1b-2 — VT engine — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a self-contained xterm-ish terminal emulator — the cell grid,
the escape/CSI parser, SGR attributes, scroll regions, alt screen, and
a scrollback ring — as plain C in `userland/term/`, with **zero**
framebuffer or kernel dependency, proven by a headless `VTTEST.ELF`.

**Architecture:** `userland/term/vt.c` + `vt.h` own a `struct vt`: a
fixed-size cell grid (no `malloc` in libneoos), a parser state machine,
cursor + saved cursor, current SGR, scroll region, a primary/alt
screen pair, a line-ring for scrollback, and per-row dirty flags.
`vt_feed()` drives everything; `vt_cell_at()` and `vt_take_dirty()` are
how the M1b-3 renderer (and `VTTEST` now) read the result. No I/O in
`vt.c` — it is a pure function of the bytes fed to it.

**Tech Stack:** C (freestanding, `-mcmodel=large`, libneoos — `printf`
is `%s %d %u %x %c %%` only, `memset`/`memmove`/`memcpy` available, no
`malloc`, no `assert`). Headless QEMU + serial-log marker scrape. The
parallel gauntlet.

**Spec:** `docs/superpowers/specs/2026-09-01-m1b-framebuffer-terminal-design.md` (§1, §4, §5, §8, §9 row M1b-2)

## Global Constraints

- **No `malloc`.** `struct vt` holds fixed arrays sized by the
  compile-time maxima below; `VTTEST` and (later) `TERM` keep one
  `static struct vt`.
  ```c
  #define VT_MAX_COLS   200
  #define VT_MAX_ROWS   64
  #define VT_SCROLLBACK 1000     /* history lines above the screen */
  #define VT_RING       (VT_SCROLLBACK + VT_MAX_ROWS)
  ```
  `sizeof(struct vt)` ≈ `VT_RING*VT_MAX_COLS*4` (ring) `+ alt grid` ≈
  ~1.1 MB in `.bss` — fine for the large model.
- **Cell** (4 bytes, final):
  ```c
  struct vt_cell { uint8_t ch; uint8_t fg; uint8_t bg; uint8_t attr; };
  /* ch: Latin-1 byte (0x20..0xFF); 0x00 == blank.
     fg/bg: 0..255 xterm palette index, ignored when the matching
            attr default-bit is set.
     attr bits: */
  #define VT_BOLD      0x01
  #define VT_DIM       0x02
  #define VT_UNDERLINE 0x04
  #define VT_REVERSE   0x08
  #define VT_HIDDEN    0x10
  #define VT_DEFFG     0x20      /* fg is the terminal default */
  #define VT_DEFBG     0x40      /* bg is the terminal default */
  ```
  This **refines** the spec §5 sketch (`{uint8_t ch; uint16_t attr;}`)
  — 256-colour needs the two index bytes.
- **Charset:** Latin-1. Bytes `0x00`–`0x1F` and `0x7F` are controls;
  `0x20`–`0xFF` (except `0x7F`) are printable. No UTF-8 decode.
- **`vt.c` has no `#include` of anything under `dev/`, no syscalls, no
  globals that are not `const`.** The only headers are `<stdint.h>`,
  `<stddef.h>`, `"vt.h"`, and `<string.h>` for mem\*.
- **`VTTEST` is a separate `userland/term/vttest.c`** that
  `#include "vt.h"` and links `vt.c` — **not** `vt.c` compiled with a
  `-DVT_SELFTEST main()`. Refines spec §8; keeps `vt.c` free of test
  code.
- **Marker:** `VTTEST` prints exactly `[vttest] ALL PASSED` on success
  and `[vttest] FAILED: <what>` per failed check (then a non-`ALL
  PASSED` exit). Added to `REQUIRED_MARKERS`; `make test` and the
  gauntlet gate on it.

## Public API (`vt.h`) — the whole surface

```c
struct vt;                 /* opaque to callers; full def in vt.h for static alloc */
struct vt_span { int row; int col0; int col1; };   /* half-open [col0,col1) */

void vt_init(struct vt *v, int cols, int rows);
void vt_feed(struct vt *v, const uint8_t *p, size_t n);
void vt_resize(struct vt *v, int cols, int rows);

/* read-back for the renderer / tests. row is screen-relative 0..rows-1,
   adjusted by the current scrollback view offset. */
const struct vt_cell *vt_cell_at(const struct vt *v, int row, int col);
void vt_cursor(const struct vt *v, int *x, int *y, int *visible);

/* dirty rows since the last call; returns count, writes up to `max`
   spans. clears the dirty set. */
int  vt_take_dirty(struct vt *v, struct vt_span *out, int max);

/* scrollback: delta<0 scrolls toward history, >0 toward the present;
   clamped. any vt_feed of a printable char or newline snaps back to 0. */
void vt_scroll_view(struct vt *v, int delta_lines);
int  vt_view_offset(const struct vt *v);   /* >=0 lines above the live screen */
```

## Task 1: grid core + C0 controls + scrollback ring + the harness

**Files:** Create `userland/term/vt.h`, `userland/term/vt.c`,
`userland/term/vttest.c`; modify `Makefile`.

**Interfaces:**
- Produces: everything in the API block above, but `vt_feed` handles
  only printable bytes + `BS CR LF HT BEL` this task (no `ESC`).
- The ring: `struct vt_cell ring[VT_RING][VT_MAX_COLS]`, `int top`
  (ring index of screen row 0), `int base` (ring index of the oldest
  history line), `int history` (lines of history, 0..VT_SCROLLBACK).
  Screen row r is `ring[(top + r) % VT_RING]`. Scrolling the screen up
  by one: advance `top`, clear the new bottom row, bump `history`
  (capped), advance `base` when the ring is full.

```c
#include <stdint.h>
#include <string.h>
#include <stdio.h>
#include "vt.h"

static int failures;
#define CHECK(cond, msg) do { if (!(cond)) { \
    printf("[vttest] FAILED: %s\n", msg); failures++; } } while (0)

static struct vt V;

static char cell_ch(int r, int c) {
    const struct vt_cell *x = vt_cell_at(&V, r, c);
    return x ? (char)x->ch : '?';
}
static void feed(const char *s) { vt_feed(&V, (const uint8_t *)s, strlen(s)); }

static void test_print_and_wrap(void) {
    vt_init(&V, 10, 4);
    feed("hi");
    CHECK(cell_ch(0,0) == 'h' && cell_ch(0,1) == 'i', "basic print");
    int x, y, vis; vt_cursor(&V, &x, &y, &vis);
    CHECK(x == 2 && y == 0, "cursor after print");
    feed("2345678");                 /* fills the row, col 9 written, then wrap pending */
    CHECK(cell_ch(0,9) == '8', "col 9");
    feed("X");                        /* wraps to row 1 col 0 */
    CHECK(cell_ch(1,0) == 'X', "autowrap to next row");
}

static void test_c0(void) {
    vt_init(&V, 10, 4);
    feed("abc\r");                    /* CR: col -> 0 */
    int x,y,v; vt_cursor(&V,&x,&y,&v);
    CHECK(x == 0 && y == 0, "CR");
    feed("Z");
    CHECK(cell_ch(0,0) == 'Z', "overwrite after CR");
    feed("\n");                       /* LF: row++ (no col change on a bare LF) */
    vt_cursor(&V,&x,&y,&v);
    CHECK(y == 1 && x == 1, "LF row advance, col kept");
    feed("\bq");                      /* BS then print */
    CHECK(cell_ch(1,0) == 'q', "BS then print");
    feed("\t");                       /* HT -> next multiple of 8 */
    vt_cursor(&V,&x,&y,&v);
    CHECK(x == 8, "tab stop");
}

static void test_scroll_and_history(void) {
    vt_init(&V, 4, 2);               /* 2 visible rows */
    feed("a\r\nb\r\nc");             /* 'a' scrolls into history, screen shows b / c */
    CHECK(cell_ch(0,0) == 'b' && cell_ch(1,0) == 'c', "screen after scroll");
    CHECK(vt_view_offset(&V) == 0, "view at bottom");
    vt_scroll_view(&V, -1);
    CHECK(vt_view_offset(&V) == 1, "scrolled one line into history");
    CHECK(cell_ch(0,0) == 'a', "history line visible");
    feed("d");                        /* printable -> snap to bottom */
    CHECK(vt_view_offset(&V) == 0, "snap back on output");
}

static void test_dirty(void) {
    vt_init(&V, 8, 4);
    struct vt_span sp[8];
    vt_take_dirty(&V, sp, 8);         /* clear whatever init dirtied */
    feed("x");
    int n = vt_take_dirty(&V, sp, 8);
    CHECK(n == 1 && sp[0].row == 0, "one dirty row after a print");
    n = vt_take_dirty(&V, sp, 8);
    CHECK(n == 0, "dirty set cleared");
}

int main(void) {
    test_print_and_wrap();
    test_c0();
    test_scroll_and_history();
    test_dirty();
    if (failures == 0) { printf("[vttest] ALL PASSED\n"); return 0; }
    printf("[vttest] %d FAILED\n", failures);
    return 1;
}
```

- [ ] **Step 3: implement `vt.h` + `vt.c` core**

`vt.h`: the full `struct vt` (so it can be `static`), the constants,
the API. `struct vt` fields: `int cols, rows; struct vt_cell ring[VT_RING][VT_MAX_COLS];
int top, base, history; int cx, cy; int wrap_pending; struct vt_cell cur_attr_cell;
int view; uint8_t dirty[VT_MAX_ROWS]; ` plus parser/alt/scroll-region
fields stubbed for later tasks.

`vt.c` this task:
- `vt_init`: clamp cols/rows to the maxima, `memset` the ring to a
  blank cell (`ch=0, attr=VT_DEFFG|VT_DEFBG`), reset cursor/top/base/
  history/view, mark all rows dirty.
- `put_char(v, ch)`: if `wrap_pending`, do the wrap (cx=0, cursor
  down = `index_down` which scrolls at the bottom), clear
  `wrap_pending`. Write `cur_attr_cell` with `.ch = ch` at
  `(cy,cx)`, dirty row `cy`. `cx++`; if `cx == cols` set
  `wrap_pending`, `cx = cols-1` held.
- `index_down(v)`: if `cy < scroll_bottom` (rows-1 for now) `cy++`;
  else scroll the region up one (this task: whole screen → advance
  `top`, blank new bottom row, `history = min(history+1, VT_SCROLLBACK)`,
  advance `base` if the ring wrapped, all visible rows dirty).
- C0 in `vt_feed`: `\b` → `cx = max(0, cx-1)`, clear wrap_pending;
  `\r` → `cx = 0`, clear wrap_pending; `\n` (and `\v`,`\f`) →
  `index_down`; `\t` → `cx = min(cols-1, (cx & ~7) + 8)`; `\a` →
  set a `bell` flag (test reads nothing; renderer flashes later);
  `0x00` and other C0 → ignored.
- `vt_cell_at(v, r, c)`: bounds-check; the ring row is
  `(top + r - view) % VT_RING` (view shifts the window up into
  history); return `&ring[...][c]`.
- `vt_cursor`: write `cx, cy, cursor_visible` (default 1).
- `vt_take_dirty`: for each `r` with `dirty[r]`, emit
  `{r, 0, cols}`, clear; return count (capped at `max`).
- `vt_scroll_view(v, d)`: `view = clamp(view - d, 0, history)`.
  (`d<0` → toward history increases `view`.)
- `vt_view_offset`: return `view`.
- Snap-to-bottom: at the top of `put_char` and `index_down`, if
  `view != 0` set `view = 0` and dirty all rows.
- `vt_resize`: this task, just clamp+re-`memset`+re-home (a real
  reflow is not required — spec does not promise it).

- [ ] **Step 2: implement the state machine in `vt.c`**

- `vt_feed` switches on `v->pstate`:
  - `GROUND`: `0x1b` → `ESC`; C0 → the Task-1 handlers; else
    `put_char`.
  - `ESC`: `[` → `CSI` (reset `params`, `nparam`, `priv=0`,
    `inter=0`); `7` → save cursor; `8` → restore cursor; `c` → RIS
    (Task 3); `(` `)` etc. → `ESC_CHARSET` (consume one more byte,
    ignore); anything else → back to `GROUND`.
  - `CSI`: `0x30..0x39` → accumulate current param; `;` → next param;
    `?` (only right after `[`) → `priv = 1`; `0x20..0x2F` → `inter`
    byte; `0x40..0x7E` → **dispatch**, back to `GROUND`; C0 mid-
    sequence → execute it and stay in `CSI` (xterm behaviour).
  - `params[]` is `int[16]`, missing param reads as 0 → treated as
    "default" by each handler.
- CSI finals to implement:
  | final | name | effect |
  |---|---|---|
  | `A B C D` | CUU/CUD/CUF/CUB | move by `max(1,p0)`, clamp to grid |
  | `E F` | CNL/CPL | col 0, then down/up `max(1,p0)` |
  | `G` `` ` `` | CHA/HPA | col = `p0-1` clamped |
  | `d` | VPA | row = `p0-1` clamped |
  | `H f` | CUP/HVP | row=`p0-1`, col=`p1-1`, clamped; clears wrap_pending |
  | `J` | ED | 0: cursor→end; 1: start→cursor; 2/3: whole screen. blank cells = `cur default`, dirty affected rows |
  | `K` | EL | 0/1/2 on the cursor's row |
  | `L M` | IL/DL | insert/delete `max(1,p0)` blank lines at the cursor row, within the scroll region |
  | `S T` | SU/SD | scroll region up/down `max(1,p0)` |
  | `r` | DECSTBM | `top=p0-1, bot=p1-1` (defaults full screen), then cursor home. store `sr_top,sr_bot` |
  | `s u` | SCOSC/SCORC | save/restore cursor (alias of DECSC/DECRC) |
  | `h l` (priv `?25`) | DECTCEM | `cursor_visible = (final=='h')` |
  | `h l` (priv `?1049`, `?2004`, `?1000`, `?1006`, `?1015`, `?7`) | Task 3 / accept-noop |
  | `m` | SGR | below |
  | `n` (`?6`/`5`) | DSR | ignore (no reply channel in `vt`; TERM handles device replies) |
- `index_down` / a new `index_up` now respect `sr_top`/`sr_bot`: a
  scroll only moves rows `sr_top..sr_bot`, and only a scroll at
  `sr_bot == rows-1` feeds a line into the scrollback ring (a scroll
  inside a smaller region does not touch history).
- **SGR** (`apply_sgr(v, params, n)`):
  `0` reset to `VT_DEFFG|VT_DEFBG`, no other bits; `1` BOLD; `2` DIM;
  `4` UNDERLINE; `7` REVERSE; `8` HIDDEN; `22` clear BOLD|DIM; `24`
  clear UNDERLINE; `27` clear REVERSE; `28` clear HIDDEN;
  `30..37` fg = n-30, clear DEFFG; `39` DEFFG; `40..47` bg = n-40,
  clear DEFBG; `49` DEFBG; `90..97` fg = n-90+8; `100..107` bg =
  n-100+8; `38`/`48` followed by `5;idx` → fg/bg = idx (0..255), or
  `2;r;g;b` → map to nearest xterm-256 index (a small helper). An
  empty SGR (`\x1b[m`) is `0`.
