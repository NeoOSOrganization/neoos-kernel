# D3 — ICMP: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: use
> `superpowers:executing-plans`. Steps use `- [ ]` checkboxes.

**Goal:** the host can `ping` NeoOS, NeoOS can ping out, and a UDP
datagram to a closed port is answered rather than swallowed.

**Architecture:** one new file, `icmp.c`, hooked into `net_ipv4_input`'s
protocol switch beside UDP. It does three things — echo reply, echo
request with a reply demux, and destination-unreachable generation — and
refuses the rest of ICMP.

**Tech Stack:** C11 freestanding; in-kernel selftests over the serial
log, as everywhere else in this kernel.

**Spec:** `docs/superpowers/specs/2026-09-04-d2-d5-network-stack-design.md` §4

**Status:** DONE. Results, including everything the design did not
predict, are in the spec's section 10.

## Global Constraints

- **Depends on D2.** `route_lookup`, `eth_output_ipv4` and ARP must be
  in place; an echo request to 10.0.2.2 resolves the gateway first.
- No dynamic allocation. The echo reply is built in a stack buffer.
- `[icmp] ALL PASSED` joins `REQUIRED_MARKERS` in the same commit.
- Detectors proven by breaking them; table recorded in the spec results.

### Task 1: Echo reply — the host can ping NeoOS

**Files:**
- Create: `kernel/net/icmp.h`, `kernel/net/icmp.c`
- Modify: `kernel/net/net.c:163` (`net_ipv4_input`'s protocol switch)

**Interfaces:**
- Produces:
```c
#define ICMP_ECHO_REPLY   0
#define ICMP_DEST_UNREACH 3
#define ICMP_ECHO_REQUEST 8
#define ICMP_UNREACH_PORT 3      // code, under type 3

struct icmp_header {
    uint8_t  type, code;
    uint16_t checksum_n;
    uint16_t id_n, seq_n;        // echo only; "unused" for unreachable
} __attribute__((packed));       // 8 bytes

void icmp_input(struct netdev *dev, const struct ipv4_header *ip,
                const uint8_t *msg, uint32_t len);
// Sends one echo request. Returns 0, or a negative errno.
int  icmp_echo_send(uint32_t dst_n, uint16_t id, uint16_t seq);
// Ticks when a reply matching (id, seq) has been seen, or 0.
// Zero means "no reply yet"; the caller polls it.
uint64_t icmp_echo_reply_at(uint16_t id, uint16_t seq);
// Quotes the IP header and the first 8 bytes of its payload, as the RFC
// requires and as every traceroute implementation depends on.
void icmp_port_unreachable(struct netdev *dev, const struct ipv4_header *ip,
                           const uint8_t *payload, uint32_t payload_len);
void icmp_stats(uint64_t *echo_rx, uint64_t *echo_tx, uint64_t *replies_tx,
                uint64_t *unreach_tx, uint64_t *rate_limited);
void icmp_selftest(void);
```

- [ ] **Step 1: Write the failing selftest** (`icmp_selftest`, part 1):

```c
// An injected echo request produces a byte-exact reply.
uint8_t buf[64];
struct ipv4_header *ip  = (struct ipv4_header *)buf;
struct icmp_header *ic  = (struct icmp_header *)(buf + 20);
// ... fill ip: src 10.0.2.99, dst = dev->ip_n, proto 1, len 20+8+16
ic->type = ICMP_ECHO_REQUEST; ic->code = 0;
ic->id_n = htons_k(0xBEEF);   ic->seq_n = htons_k(7);
for (int i = 0; i < 16; i++) { buf[28 + i] = (uint8_t)(0xA0 + i); }
ic->checksum_n = 0;
ic->checksum_n = ~net_checksum(ic, 8 + 16, 0);

uint64_t before = icmp_replies_tx();
icmp_input(dev, ip, (const uint8_t *)ic, 8 + 16);
if (icmp_replies_tx() != before + 1) {
    serial_write_string("[icmp] FAILED: no reply to an echo request\n");
    failed = 1;
}
// The reply is captured by a test hook rather than sniffed off the wire.
const uint8_t *r = icmp_last_reply();     // 8 + payload
if (r[0] != ICMP_ECHO_REPLY) {
    serial_write_string("[icmp] FAILED: reply is not type 0\n"); failed = 1;
}
if (((const struct icmp_header *)r)->id_n != htons_k(0xBEEF) ||
    ((const struct icmp_header *)r)->seq_n != htons_k(7)) {
    serial_write_string("[icmp] FAILED: reply did not echo id/seq\n"); failed = 1;
}
for (int i = 0; i < 16; i++) {
    if (r[8 + i] != (uint8_t)(0xA0 + i)) {
        serial_write_string("[icmp] FAILED: reply did not echo the payload\n");
        failed = 1; break;
    }
}
if (net_checksum(r, 8 + 16, 0) != 0xFFFF) {
    serial_write_string("[icmp] FAILED: reply checksum is wrong\n"); failed = 1;
}
// A request with a BAD checksum is dropped.
ic->checksum_n ^= htons_k(0x0100);
before = icmp_replies_tx();
icmp_input(dev, ip, (const uint8_t *)ic, 8 + 16);
if (icmp_replies_tx() != before) {
    serial_write_string("[icmp] FAILED: replied to a corrupt echo request\n");
    failed = 1;
}
```

The payload check is the one that matters: an implementation that
builds a reply from scratch instead of copying passes every other
assertion and breaks `ping -s 1000` on the first real use.

- [ ] **Step 2: Run and watch it fail.** `make test`; expect a link
      error or `[icmp] FAILED`.

- [ ] **Step 3: Implement echo reply.** Verify the checksum over the
      whole message, copy the message into a stack buffer, set
      `type = 0`, zero and recompute the checksum, swap src/dst and call
      `net_ipv4_output(ip->dst_n, ip->src_n, IPPROTO_ICMP, ...)`. Record
      the outgoing bytes in a `last_reply[]` buffer for the selftest.
      Cap the echoed payload at 1472 bytes and drop anything longer —
      fragmentation is not in this track and a too-large reply must be
      *refused*, not truncated into a lie.

- [ ] **Step 4: Dispatch it.** In `net_ipv4_input`, add
      `case IPPROTO_ICMP: icmp_input(dev, ip, payload, plen); break;`.

- [ ] **Step 5: `make test`.** Expected the part-1 assertions to pass.

- [ ] **Step 6: Commit.**

```bash
git add kernel/net/icmp.c kernel/net/icmp.h kernel/net/net.c
git commit -m "icmp: answer an echo request"
```

### Task 2: Echo request, and a real ping over the wire

**Files:** Modify `kernel/net/icmp.c`, `kernel/net/icmp.h`

- [ ] **Step 1: Extend the selftest** (part 2):

```c
// A REAL ping to the gateway, through the real driver. slirp answers
// pings addressed to itself, so this needs no host cooperation.
if (net_device()) {
    uint64_t t0 = timer_ticks();
    if (icmp_echo_send(0x0202000Au, 0x1234, 1) != 0) {
        serial_write_string("[icmp] FAILED: could not send an echo request\n");
        failed = 1;
    } else {
        uint64_t at = 0;
        for (int i = 0; i < 300 && !at; i++) {   // 3s at 100Hz
            __asm__ volatile("hlt");
            at = icmp_echo_reply_at(0x1234, 1);
        }
        if (!at) {
            serial_write_string("[icmp] FAILED: no echo reply from the gateway\n");
            failed = 1;
        } else {
            serial_write_string("[icmp] gateway rtt ticks=");
            serial_write_hex64(at - t0);
            serial_write_string("\n");
        }
    }
}
```

`hlt`, not `schedule()` — kmain is not a thread. The reply is delivered
by the netrx thread on *another CPU*, exactly as D1's ARP wait is.
On a single-CPU machine nothing drains the queue, so the arm reports
**SKIPPED**, not FAILED, when `smp_cpu_count() < 2`.

- [ ] **Step 2:** Implement `icmp_echo_send` (build, checksum,
      `net_ipv4_output` with `src_n = 0` so D2's source selection picks
      the interface) and the reply side of `icmp_input`: a type-0
      message records `(id, seq, timer_ticks())` in a 4-entry ring that
      `icmp_echo_reply_at` searches. Four entries because the only
      consumer is one selftest and, later, a `ping` with one outstanding
      probe.

- [ ] **Step 3: `make test`,** expect the rtt line and no FAILED.

- [ ] **Step 4: Prove the detector.** Send the request with the
      destination and source swapped; confirm
      `no echo reply from the gateway`; revert.

- [ ] **Step 5: Commit.**

```bash
git add kernel/net/icmp.c kernel/net/icmp.h
git commit -m "icmp: send an echo request, and match the reply"
```

### Task 3: Port unreachable, and the rate limiter

**Files:** Modify `kernel/net/icmp.c`, `kernel/net/net.c` (`udp_input`)

- [ ] **Step 1: Extend the selftest** (part 3):

```c
// A UDP datagram to a closed port produces an unreachable that QUOTES
// the offending header.
uint64_t u0 = icmp_unreach_tx();
net_udp_output(IP_LOOPBACK_N, htons_k(4444),
               IP_LOOPBACK_N, htons_k(9), (const uint8_t *)"x", 1);
if (icmp_unreach_tx() != u0 + 1) {
    serial_write_string("[icmp] FAILED: closed UDP port was silent\n");
    failed = 1;
}
const uint8_t *q = icmp_last_unreach();       // icmp hdr + quoted 20+8
if (q[0] != ICMP_DEST_UNREACH || q[1] != ICMP_UNREACH_PORT) {
    serial_write_string("[icmp] FAILED: unreachable has the wrong type/code\n");
    failed = 1;
}
if (q[8 + 9] != IPPROTO_UDP) {
    serial_write_string("[icmp] FAILED: unreachable did not quote the IP header\n");
    failed = 1;
}
if (*(const uint16_t *)(q + 8 + 20 + 2) != htons_k(9)) {
    serial_write_string("[icmp] FAILED: unreachable did not quote the UDP ports\n");
    failed = 1;
}
// The rate limiter limits: ten more in a burst produce at most one.
u0 = icmp_unreach_tx();
for (int i = 0; i < 10; i++) {
    net_udp_output(IP_LOOPBACK_N, htons_k(4444),
                   IP_LOOPBACK_N, htons_k(9), (const uint8_t *)"x", 1);
}
if (icmp_unreach_tx() - u0 > 1) {
    serial_write_string("[icmp] FAILED: rate limiter did not limit\n");
    failed = 1;
}
if (icmp_rate_limited() == 0) {
    serial_write_string("[icmp] FAILED: rate limiter limited without counting\n");
    failed = 1;
}
```

- [ ] **Step 2:** Implement `icmp_port_unreachable`: type 3 code 3, four
      zero bytes where id/seq sit, then the IP header and the first 8
      bytes of its payload. Send it back to `ip->src_n`.

- [ ] **Step 3:** Implement the rate limiter — one generated unreachable
      per 100 ms globally (`last_unreach_tick`, `TIMER_HZ / 10`),
      counting suppressions in `rate_limited`. Not for security: a
      misconfigured peer blasting a closed port would otherwise fill the
      wire with our replies.

- [ ] **Step 4:** In `net.c`'s `udp_input`, call
      `icmp_port_unreachable` on the path that currently drops a
      datagram no socket claimed. **Never** for a datagram sent to a
      broadcast or multicast destination — replying to those is how a
      host becomes an amplifier.

- [ ] **Step 5: `make test`,** expect `[icmp] ALL PASSED`.

- [ ] **Step 6: Prove the detectors:** (a) quote only the IP header and
      not the 8 payload bytes → `did not quote the UDP ports`; (b)
      disable the limiter → `rate limiter did not limit`. Revert both.

- [ ] **Step 7: Add `"[icmp] ALL PASSED"` to `REQUIRED_MARKERS`.**

- [ ] **Step 8: Commit.**

```bash

```
